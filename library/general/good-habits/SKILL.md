# Good Habits

## When to use this skill

- BEFORE DOING ANYTHING

## Prefer Python over shell. 


- Especially for prolonged, chained commands, and reusable scripts, use Python can be a better choice.
- Never write things like `.ps1`, `.cmd`, `.sh` in any project as script.
- Use shell commands if and only if:
  - it is a one-liner simple command.
  - there's no Python available.
  - it is something that must be done with, or designed for native shell.
