# MISSION.md Format

Use a mission file for a persistent course's goals, scope, and constraints. Let it guide planning alongside the learner's current request. Create it when a course plan needs it.

## Template

```md
# Mission: {Topic}

## Goal
{What the learner wants to understand or be able to do. Curiosity or theoretical understanding is a sufficient goal.}

## Success looks like
- {A capability, question they want to answer, or result they want to explain}

## Constraints
- {Relevant background, time, tools, and teaching preferences}

## Out of scope
- {Topics the learner explicitly excludes, if any}
```

## Rules

- Use goals and constraints already stated. Ask only about missing information that would change the plan.
- Keep unresolved details open and refine them as the learner's interests develop.
- Update the file when the learner changes their goals. Clarify consequential ambiguities before changing scope.
- Keep it concise and omit empty sections. Use separate topic sections or files only when they make distinct learning plans easier to follow.
