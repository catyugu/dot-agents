# GLOSSARY.md Format

Use `GLOSSARY.md` as a reference for recurring terms and notation in a persistent course. Add a term when a shared definition will help the learner read or revisit the material.

## Structure

```md
# {Topic} Glossary

**Residual**:
For the linear system Ax = b, the residual at an approximation x is r = b - Ax.

**A-inner product**:
For a real symmetric positive definite matrix A, define ⟨u, v⟩_A = uᵀAv.
```

## Rules

- Follow established disciplinary usage. State a local convention or notation choice when the field has multiple meanings.
- Give enough context and assumptions for an accurate definition. Use additional sentences or an equation when needed.
- Use previously defined terms where they aid understanding. Check for circular definitions and chains of unexplained terminology.
- Include standard synonyms when useful; preserve distinctions between related concepts.
- Keep terminology consistent across materials and explain a change of convention when reading another source.
- Group terms when natural clusters emerge and correct inaccurate entries in place.
- Record evidence of the learner's understanding in learning records; a glossary entry records the term's meaning.
