# RESOURCES.md Format

Use `RESOURCES.md` to keep sources worth returning to during a persistent course. Add entries when they will help future explanations or study.

## Structure

```md
# {Topic} Resources

- [Resource title — author or organization](https://example.com)
  Covers: {relevant topics}. Use for: {specific questions or learning stage}.
  {Limitations, prerequisites, or version, when relevant.}
```

## Rules

- Choose sources appropriate to the claim: textbooks for established theory, primary research for research findings, official documentation for software behavior, and practitioner accounts for experience-based advice.
- Annotate what each source supports and when to use it. Check the relevant content before citing it.
- Group by topic or resource type when the list benefits from it. Include communities when they serve the learner's goals and preferences.
- Record important gaps that affect the course's next steps.
- Replace unreliable or obsolete entries and remove resources that no longer serve the course.
