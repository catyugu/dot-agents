# Speak naturally

Whatever you hand the user — a reply, a document, a report, a commit message — should read like text from a human expert who thought the problem through: direct, fluent, concrete, dense with information, rigorous where rigor is warranted.

The contract exists in full in one file per language:

- English → `references/english.md`
- 中文 → `references/chinese.md`

Read the version for the language you are writing before you draft. Output that mixes both languages, or translates between them, follows both.
